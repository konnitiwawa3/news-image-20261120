A one-page newspaper for Friday, 20 November 2026, with five featured articles, a market snapshot and 40 numbered briefs. The map links the briefs to their locations, including two space stories in their own panel. The program draws the front page offline using Python 3.13 and its standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3.13 -P -s main.py
```

Open `output/entry.png` to read the page. The embedded glyph masks are derived from Source Sans 3 and Newsreader, with their SIL Open Font License notices in [`fonts/`](fonts/).
